## What's included (free)

- Unlimited local downloads via yt-dlp
- Video (up to 4K), audio, subtitles, Instagram, Twitch VODs, Video Clipper, Video Divider, Video to GIF and Music Finder
- Automatic install and updates of yt-dlp and FFmpeg
- Recents history, custom save folders, six accent themes
- Windows installer from GitHub Releases; macOS and Linux via source build

## What's not included

- No paid tiers, subscriptions or in-app purchases
- No cloud processing: all downloads run on your machine
- No support contract (community support via GitHub Issues)
