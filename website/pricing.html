Pricing

Last updated: August 13, 2026 · Version 1.8.2

YT-DLP GUI costs $0. The entire desktop app is MIT-licensed for personal and commercial use. There are no paid tiers, in-app purchases, or ads.

Full application $0 MIT — free for personal and commercial use

What's included

  • Unlimited local downloads via yt-dlp
  • Video up to 4K, audio, subtitles, Instagram, clipper, video divider, GIF converter, and Music Finder
  • Auto-install of yt-dlp and ffmpeg
  • Six UI accent themes, recents history, custom save paths
  • Windows installer from GitHub Releases; macOS and Linux via source build

What's not included

  • No paid tiers, subscriptions, or in-app purchases
  • No cloud processing — downloads run on your machine
  • No official support SLA (community support via GitHub Issues)
